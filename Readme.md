# SpendWise Dashboard

## Project Description

SpendWise is a personal finance dashboard designed
to help users monitor their income, expenses,
savings and financial activities.

The dashboard provides a simple and modern interface
for managing personal finances.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- CSS Custom Properties
- Media Queries
- DOM Manipulation

## Project Files

### 1. index.html

Contains the structure of the dashboard.

It includes:
- Sidebar navigation
- Dashboard header
- Financial summary cards
- Six expense category cards
- Recent transactions
- Add expense form
- Footer

### 2. style.css

Controls the appearance and layout.

It includes:
- Colour variables
- Dashboard styling
- CSS Grid layout
- Flexbox layout
- Responsive design
- Hover animations
- Keyboard focus animations
- Dark theme

### 3. script.js

Provides interactive dashboard functionality.

It includes:
- Expense calculations
- Adding new expenses
- Updating financial summaries
- Displaying transactions
- Category interactions
- Dark mode switching
- Sidebar navigation

### 4. README.md

Provides project information,
technologies used and file descriptions.

## Main Features

1. Modern financial dashboard.
2. Responsive layout for mobile devices.
3. Six financial categories.
4. Monthly income and expense summaries.
5. Interactive expense form.
6. Automatic expense calculations.
7. Dark mode option.
8. Recent transaction display.
9. Hover and keyboard focus effects.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. View and interact with the dashboard.
